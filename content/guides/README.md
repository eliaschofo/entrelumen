# Guías del pack (capítulos informativos)

Capítulos de quests que documentan el pack para quien recién empieza: cada mod importante, QoL, logística, construcción, granjas, tips y los sistemas propios de ENTRELUMEN. Son opcionales y no mueven la historia. El formato está en `tools/check_guides.py`; se valida con `python tools/check_guides.py`. El generador de quests los incorpora en una etapa aparte.

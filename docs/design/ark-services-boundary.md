# Practical Ark services: implementation boundary

Engineering is an implemented material repair workshop. Arcana is an implemented compound-book library. Both require a complete physical Ark, operate only on deliberate interaction, preserve free gifts and do not award campaign progress. Habitation now offers temporary personal expedition lodging with conservative restoration of the previous home. Its complete physical Ark is checked at registration; an existing reservation then needs only its own module and a safe exit. Bounded evidence and limitations are in `ark-workshop-magic-runtime.json`, `arcane-building-runtime.json` and `habitation-restart-runtime.json`.

The remaining three modules retain their current diagnostics, team journals and recoverable commissioning deposits. Those interactions do not yet satisfy the acceptance requirement for six practical endgame benefits. The following are design candidates, not committed gameplay or implemented features:

| Module | Candidate and intended contribution | Evidence required before selection |
| --- | --- | --- |
| Nature | Selection pending; generic seed propagation rejected after native overlap inspection | Botany Pots already retains planted specimens while harvesting, Mystical Agriculture already crafts and reprocesses seeds, and Farmer's Delight/Productive Bees already improve crop growth or harvesting. Select a distinct conservation service before implementation; no generic seed or bee-genetics duplication. |
| Exploration | Expedition port connecting aircraft operations between established Arks | Check existing Waystones Warp Plates with pinned Immersive Aircraft first; require preservation of passengers, cargo and native fuel, safe landing, loaded endpoints and cancellation without partial relocation or duplication. The existing signal station already binds compasses; another generic locator adds no distinct service. |
| Logistics | A paid physical parcel between explicitly linked Ark endpoints | Audit overlap with existing dimensional storage, registered endpoints, destination capacity, restart recovery and atomic inventory ownership before introducing persistent transfers. Never silently load an offline destination or pull from arbitrary remote inventories. |

Astra's design review retained these as exploratory options. Transport and seed proposals remain unimplemented; the lodging service is described separately in `ark-habitation.md`. Prefer native mechanisms when they fulfill a distinctive player need. Each selected service still needs its own constrained implementation and runtime proof; six generic buffs or repeated journal buttons are not a substitute.

Native Nature overlap inspection (2026-09-23): pinned client JAR hashes matched the catalog. Representative entries were `botanypots` wheat crop, `mysticalagriculture:seed/crafting/iron`, `mysticalagriculture:seed/reprocessor/iron`, Farmer's Delight rich-soil growth and Productive Bees farmer goals. This was static inspection, not new runtime evidence. Potential full-output handling in Botany Pots remains an unconfirmed observation, not a selected Ark mechanic or an authorized upstream behavior change.

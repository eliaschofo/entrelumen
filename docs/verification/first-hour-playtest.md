2. Para cada hito de la tabla, capturá el panel con faltantes o prerrequisitos, reuní los materiales y pulsá **Entregar / Deliver**. Anotá hora de cierre, inventario antes/después, progreso FTB y progreso del Atlas. Usá **Actualizar / Refresh** si la pantalla tarda en reflejar el estado; registrá si fue necesario. Possession and optional checkmarks must not record a milestone.
3. Tras **Primera señal / First Signal**, capturá **5/5**, el núcleo de señal y **Avanzar / Advance**; pulsá Avanzar y capturá el Acto II abierto. 4. Al minuto 60, capturá pantalla, inventario y progreso aunque falten hitos. Anotá el primer bloqueo, material que faltó, tiempo invertido en buscarlo, muerte/recuperación y si la UI indicó correctamente el faltante.
